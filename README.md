# MyProjectTreker

Android-приложение для управления задачами, повторениями, подзадачами и напоминаниями.

## Возможности

- Создание и редактирование задач
- Одноразовые задачи
- Ежедневные повторения
- Еженедельные повторения
- Ежемесячные повторения
- Ежегодные повторения
- Курсы задач на ограниченный период
- Подзадачи
- Напоминания
- Настройка времени напоминания
- Дополнительные времена для задач с курсом
- Выбор звука уведомлений
- Вибрация
- Светлая и тёмная тема
- Поддержка нескольких языков
- Локальное хранение данных
- Просмотр задач по дню, месяцу и году

## Архитектура

Проект построен с использованием **MVVM** и принципов **Clean Architecture**.

Зависимости направлены от Presentation к Domain, а Data реализует интерфейсы Domain.

### Presentation

- Jetpack Compose
- ViewModel
- Navigation
- UI-компоненты
- Локализация интерфейса

### Domain

- Модели предметной области
- Интерфейсы Repository
- Бизнес-логика
- Use Cases
- Доменные сервисы

### Data

- Room
- DAO
- Реализации Repository
- Локальное хранение настроек
- Система напоминаний
- Работа со звуком и рекламной инфраструктурой

## Технологии

- Kotlin
- Jetpack Compose
- Room
- Coroutines
- Flow
- AlarmManager
- BroadcastReceiver
- Android Notifications

## Повторения

Приложение поддерживает следующие типы повторений:

- **Один раз**
- **Ежедневно**
- **Еженедельно**
- **Ежемесячно**
- **Ежегодно**
- **Курс**

Для еженедельных задач можно выбирать дни недели.

Для задач с типом «Курс» поддерживается ограниченный период выполнения и дополнительные времена.

## Подзадачи

Задача может содержать несколько подзадач, которые можно отмечать как выполненные независимо от основной задачи.

## Напоминания

Для задач можно настроить напоминания относительно заданного времени.

Поддерживаются:

- время напоминания до выполнения задачи;
- дополнительные времена для задач с курсом;
- выбор звука уведомления;
- вибрация.

Напоминания восстанавливаются после перезагрузки устройства.

## Локализация

Приложение поддерживает несколько языков интерфейса и использует Android resource localization для переводов.
